> [!TIP]
> Docker Agentic Platform signups receive a one-time promotional
> credit toward cloud compute usage. To review your balance, see
> [Credits](/manuals/billing/_index.md#credits).

Docker Agentic Platform brings
[MCP Gateway](/manuals/ai/mcp-catalog-and-toolkit/mcp-gateway.md) and
[Cloud Sandboxes](/manuals/ai/sandboxes/_index.md) together for individual
developers. The plan includes MCP Gateway access with a monthly tool-call
allowance, higher MCP Gateway limits, Docker Cloud Sandboxes with concurrent
sandboxes, snapshot storage, and private Docker Hub repositories.

Docker Agentic Platform is a pay-as-you-go plan. There is no
recurring subscription fee. You pay for the usage you accrue. To add it to
your Docker subscription, see
[Manage plans](/manuals/subscription/manage.md).

## Usage

After you subscribe, your invoice reflects metered, pay-as-you-go usage.
Docker meters compute usage based on the vCPU and memory your sandboxes
consume over time, along with outbound data transfer. To monitor usage, see
[Usage](/manuals/billing/_index.md#usage).

Docker Agentic Platform requires that you bring your own API keys
for inference. Your inference provider handles those costs.

> [!NOTE]
> Docker Agentic Platform plans are a Docker Personal and Docker Pro
> exclusive.

## Billing behaviors

Docker Agentic Platform includes higher limits for Docker Cloud
Sandboxes. Docker bills accrued usage monthly on the first of the month.

## Cancel a plan

Canceling Docker Agentic Platform disables plan renewal at the
start of the next month. Docker bills you for usage at the end of the plan
period.

1. Sign in to [Docker Home](https://app.docker.com/) and go to **Billing**.
1. From **Active plans**, select **Manage** next to
   **Docker Agentic Platform**.
1. Select **Cancel subscription**.
1. Review usage behavior, then select **Cancel subscription** to confirm.
