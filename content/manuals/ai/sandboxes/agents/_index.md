Choose an agent, then follow its authentication and configuration guide.
Agent availability depends on the environment, launch interface, and installed
kit catalog. A local integration does not establish cloud availability.

## Shared sandbox tasks

Use [CLI tasks](/manuals/ai/sandboxes/cli/_index.md) for files, ports, MCP servers, and lifecycle
operations. See [Secrets](/manuals/ai/sandboxes/concepts/secrets.md) for the credential model.
Agent pages cover provider choices and agent-specific configuration.

To package an agent or add tools, see [Author kits](/manuals/ai/sandboxes/author-kits/_index.md).
