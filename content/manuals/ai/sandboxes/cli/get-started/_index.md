Install `sbx` and choose where to run your first sandbox. Local and cloud
sandboxes use the same CLI, with different setup requirements.

1. [Install and sign in](/manuals/ai/sandboxes/cli/get-started/install.md).
2. Follow the [local quickstart](/manuals/ai/sandboxes/cli/get-started/local.md)
   for a sandbox on your machine, or the
   [cloud quickstart](/manuals/ai/sandboxes/cli/get-started/cloud.md) for
   Docker-managed compute.
3. Use [Run and manage](/manuals/ai/sandboxes/cli/manage/_index.md) to create,
   stop, resume, and remove sandboxes after setup.

Before adapting an existing workflow, check
[Local and cloud differences](/manuals/ai/sandboxes/cli/get-started/local-vs-cloud.md).
For a comparison with the Console or SDK, see
[Choose an environment and interface](/manuals/ai/sandboxes/choose.md).
