Use the Docker Sandboxes API to manage sandbox environments from applications,
scripts, and development tools. Choose the documentation for the API you use.

## API v1

[API v1 and its TypeScript SDK](v1/_index.md) manage cloud sandboxes. This section
includes the `@docker/sandboxes` installation instructions, getting started
guide, cookbook, and [REST API reference](/reference/api/sandboxes/latest/).

## API v2

[API v2](v2/_index.md) is a redesign for managing local and cloud sandboxes.
Its documentation is in development. The section introduces the concepts and
outlines the guides to come. API examples, SDK instructions, and the v2 reference
are not included yet.

V1 examples and the `@docker/sandboxes` package documented in the v1 section
use the v1 API. They do not describe the v2 interface.

## Other ways to use sandboxes

Use [Docker Sandboxes](/manuals/ai/sandboxes/_index.md) for terminal workflows
with `sbx`. Use the
[Docker Agentic Platform Console](/manuals/agentic-platform/_index.md) to work
with cloud sandboxes in your browser.
