Start with a shell sandbox so you can run a command without configuring an agent
or model provider. Follow the local guide first, then repeat the workflow in
cloud.

1. [Run a local sandbox](local.md): connect to the local daemon, create a sandbox,
   run a command, and clean up.
2. [Run a cloud sandbox](cloud.md): use cloud authentication and repeat the same
   basic operations.

These guides are outlines. Connection commands and runnable examples will be
added after the API interface is stable.
