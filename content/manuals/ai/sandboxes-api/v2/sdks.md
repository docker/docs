SDK documentation for API v2 will describe supported languages, installation,
connection configuration, and resource management once those interfaces are
stable. SDK coverage can differ from the REST API, including support for local
daemon connections.

The `@docker/sandboxes` installation instructions in the
[v1 documentation](../v1/install.md) apply to API v1. They are not installation
instructions for this API.
