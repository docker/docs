Choose a workflow to put a cloud sandbox to work:

- [Share an application](share-app.md) through a public HTTPS URL, then withdraw access.
- [Develop remotely](remote-development.md) with VS Code or Cursor over SSH.
- [Continue local work in the cloud](local-handoff.md) and retrieve the results.

For account setup, start with [Get started](/manuals/agentic-platform/get-started.md).
For command options, see [Use cloud sandboxes](/manuals/ai/sandboxes/cloud/usage.md).
